    1. After `fleet_hosts = results...` (Task 2 of 03-03), add selection restore logic:
       ```rust
       // Restore selection by host_id lookup
       if let Some(selected_id) = self.fleet_selected_host_id {
           if let Some(idx) = fleet_hosts.iter().position(|h| h.host_id == selected_id) {
               self.fleet_selected_row = Some(idx);
           } else {
               // Previously-selected host no longer in fleet; select first host
               self.fleet_selected_row = Some(0);
               self.fleet_selected_host_id = fleet_hosts.first().map(|h| h.host_id);
           }
       } else {
           // No prior selection; select first host
           self.fleet_selected_row = Some(0);
           self.fleet_selected_host_id = fleet_hosts.first().map(|h| h.host_id);
       }
       ```
    2. Ensure this runs after fleet_hosts vec is fully populated and before UI render.
  </action>

    </automated>
